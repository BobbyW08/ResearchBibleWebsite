# Brand Style Guide

Source: Fontpair "Agent" starter kit

## Typography

| Role | Font |
|---|---|
| Headline | Space Grotesk |
| Body | DM Sans |

## Color Palette

| Role | HEX | RGB | CMYK |
|---|---|---|---|
| Background | #F1F5FF | 241, 245, 255 | 5, 4, 0, 0 |
| Text | #1E1527 | 14, 21, 39 | 64, 46, 0, 85 |
| Primary | #0F172A | 15, 23, 42 | 64, 45, 0, 84 |
| Accent | #343F58 | 52, 63, 88 | 41, 28, 0, 65 |
| Surface | #FFFFFF | 255, 255, 255 | 0, 0, 0, 0 |

## Usage Notes

- Use this palette and type pairing for consistent branding across parenting practice deliverables — Substack articles, slide decks, handouts, and workbooks.
- Space Grotesk for headlines/titles gives a modern, slightly technical feel; pair with DM Sans body copy for warmth and readability.
- Background (#F1F5FF) and Surface (#FFFFFF) work well for light layouts; Primary (#0F172A) and Text (#1E1527) provide strong dark contrast for headers or dark-mode sections.
- Accent (#343F58) can be used for secondary UI elements, buttons, or highlights.
- Border (#C6D4F3) is a soft divider/border color that complements the light background.
